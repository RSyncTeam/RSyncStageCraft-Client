# Contributing

Outside contributions are not accepted at this time. Whether and how they will
be accepted has not been decided yet; until then, please do not open pull
requests.

When contributions are accepted, each one is made under the licence of the
project it touches (inbound = outbound):

- a change to `src/RSyncStageCraft.Protocol` or `tests/RSyncStageCraft.Protocol.Tests`
  is contributed under the MIT License;
- any other change is contributed under AGPL-3.0-only.

See `NOTICE` for which licence covers which part of the repository.
